## 4. 规则沉淀（新增 P47）

- **P47 白线≠垃圾**：DROP 之前必须对未归档线跑端点搭接连通性扫描；**连续链（内部间隙
  <1mm、两端接到已分类环）是真实边界轮廓，不是装饰垃圾**。平行重复线（如 L160/L165 与
  L164 重复、L204-217 族 1mm 重复壁）才是该 DROP 的。v10 教训：把整条回路当垃圾全删，
  用户目检后又要回加——先扫连通性、分清"主链 vs 重复线"再动手。
- 微缝处理：链首尾与主环的 0.29~1.0mm 微缝是图纸固有；后续建面/共节点阶段用
  HyperMesh surface edit 或 tolerance 桥接，不在分区阶段硬凑（保持几何零改动原则）。
