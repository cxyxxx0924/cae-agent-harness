# 01 · 四分区几何判据详版

> 用户口述特征 → 可执行判据的完整映射。判据优先级：**几何 > 拓扑 > 视觉**，
> 但最终必须过人眼（渲染图）。

## 1. BELT 布带（最外闭环）

口述：左下右平直闭环、转角圆弧、**上方充气口锐角 30–40°**、宏观连续导数光滑。

可执行判据：
1. **bbox 最大**：x/y 范围包住其他所有类（NEW_CAB：x[−365,1620] y[−167,497]）
2. **切线连续链最长**：按 P36 判据追踪，BELT 主环是全线集合里最长的平滑链
   （NEW_CAB 主环 57 条线，11 个悬挂端全在顶边凸台区和充气口）
3. **充气口领圈**：从顶边向上突起的组件——外壁（大角度折线 14°→28°）+ rim
   （水平/近水平封口）+ 右侧锯齿（多条短折线）+ 内壁（回到气腔顶边缺口左端）。
   **领圈全部归 BELT，不是 TETHER**（用户明确纠正过）
4. 与 CAVITY **嵌套**：布带在气腔外侧，两环不是互斥关系

NEW_CAB 布带顶带宽 ~26mm、底边 ~14mm；主环 x=−365.2 左缘 / x=1620.2 右缘。

## 2. CAVITY 气腔（第二环 + 底部水滴）

口述：左右上贴近外环、**底部很多水滴**。

可执行判据：
1. bbox 第二大（NEW_CAB：x[−351,1579] y[−153,357]），完全落在 BELT bbox 内
2. **水滴**：底边附近有 N 个闭合小环（圆头），各通过一根短茎连到腔体边界。
   "水滴的源头"（茎 + 圆头）**属于 CAVITY，不是 TETHER**（用户明确纠正过）
3. 与充气口共边界：气腔顶边在充气口根部断开 ~410mm（NEW_CAB x 478→888），
   图纸固有，**不补**
4. 闭环 QA 目标：1 个连通 component，仅充气口缺口 2 个悬挂端

## 3. SEAM 缝线（哑铃）

口述：独立内部窄线 + **两头圆圈 = 哑铃状**，"两头圆圈才能封闭"。

可执行判据：
1. **位置**：在 BELT 内部、不贴 BELT/CAVITY 边界（缝的是布带层内）
2. **窄带**：带宽 <30mm 的长条组件
3. **两头圆圈**：两端各一个**闭合圆**。注意 IGS 的圆是**多段弧**拼的（P37），
   端点分析看像 V 头/方头——必须查折线点曲率或三点圆拟合确认是弧
4. 闭环 QA 目标：每条哑铃 **0 悬挂端**；充气口气道缝允许有悬挂端（通到领圈内部）

NEW_CAB：4 条哑铃（x≈117–1460 分布）+ 1 条充气口气道缝（L161→L162→L163→L164
→重复段→L159→L158→L157/L253）。

## 4. TETHER 拉带（凸台 + 革眼 + 补丁）

口述：顶部六七个、左一个、右一个；**充气口和水滴源头误加进来了，要回归原环**。

可执行判据：
1. **顶部凸台**：城堡状组件**跨 BELT 顶边**（hat/body/legs/foot + shoulder stacks），
   x 位置近似等距（NEW_CAB：−275/−5/283/489/962/1275/1483，7 个）
2. **左侧革眼**：40mm 圆 + 十字 + 弧（NEW_CAB：2 个，L820/L821/L5/L37/L825–L828）
3. **右侧结构**：梯带（双轨 + 锯齿缝 + 末端扣具，x 1572–1771）+ 矩形补丁
   （跨布带右缘）。判 TETHER 的依据：与 BELT 边界**交叉穿越**而不是贴边伴行
4. **排除项**（曾误分，v8 全部回归）：
   - 充气口领圈（内外壁）→ BELT
   - 水滴茎/圆头/气腔底边三段/右腰链/右上角碎片 → CAVITY
   - 布带右缘缺口补段 L762 → BELT
   - 缝线通道小连接段 L163/L205 → SEAM

## 5. 常见误分模式与识别

| 误分模式 | 识别方法 |
|---|---|
| 充气口领圈进 TETHER | 看是否"从布带顶边向上突起且带锯齿右侧"——是领圈不是凸台 |
| 水滴源头进 TETHER | 水滴圆头是闭合小环 + 短茎连腔体边界；凸台是城堡状跨顶边 |
| 气腔边缘碎片进 TETHER | bridge_scan：两端平滑搭接气腔链（NEW_CAB 找回 8 条） |
| 布带缺口补段进 TETHER | 环上 <25mm 缺口 + 游离线搭接两端 + 切线连续 |
| 缝线头圆圈被当成别的 | 多段弧拼圆（P37）；查 CIRC 三点圆拟合记录 |
| 凸台 shoulder stacks 误删 | 属于已确认的 TETHER 凸台组件，保留；BELT 顶边 9–52mm 缺口留给网格阶段桥接 |
