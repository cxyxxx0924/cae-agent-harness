## 1. 气腔 Washer 边界层

### 1.1 为什么需要

气帘气腔是 **Z±0.5 双层膜**，到布带 / 缝线 / 颈部收口处必须合拢到 Z0。
若收拢完全压在一排 5mm 单元上：

- 该排单元在充气鼓起时承受剧烈剪切 + 弯曲，容易翻折/负体积
- 缝线与布带的连接缝处应力奇异

工程做法是**在边界内侧加一圈窄单元（washer）**，把 0.5mm 的张角分散到窄带上。

### 1.2 参考模型有做吗

**没有。** 实测 `5P-BAG_004.key`：

**有。**（2026-11-01 复核，前一版"参考模型没有 washer"是错的 —— 当时的量法把
上下层混在一起量成了"第一排宽度"，量不到收拢带。）

正确量法：**取气腔里 Y=0 的边界节点，量它到最近 Y≠0 节点的平面距离**
（参考模型厚度轴是 Y，气腔在 Y=±0.5，缝线/边界处收拢到 Y=0）：

| 指标 | 参考 5P-BAG_004 | 值 |
|---|---|---|
| 气腔 PID4 中 Y=0 的节点 | — | 9,092 个 |
| Y=0 → 最近 Y≠0 的平面距离 | — | **中位 4.00 / p10 4.00 / p90 4.04 / min 2.87 / max 7.82** |
| 内部网格尺寸 | — | 5.00 mm |

分布极度集中（p10–p90 只差 0.04mm）→ **参考模型的收拢带就是一排 4mm 宽的单元**，
内部 5mm。这就是它视觉上"一圈 washer"的来源。

**我们的取值**：不能直接照搬 4mm —— 插排时边界节点内移 4mm，会把原 5mm 网格
挤出一排 **1mm 的退化单元**。取 **`W = 2.5mm`**（5mm 均分）：
第一排 2.5 + 第二排 2.5，无退化，视觉上仍是明显一圈窄带。
实测收拢带 2.57mm（p10–p90 全 2.57）。

> 若确实要 4mm：必须在插排时**删掉原第一排节点**（让位），不是简单改 W。
> 3.5mm 是折中（剩余 1.5mm 一排，质量可接受）。

### 1.3 算法（2D 层面插排，不动 HM）

输入：气腔单面网格 txt（`N nid x y z` / `S cav eid n1..n4`）

1. **自由边** = 只属于 1 个单元的边 → 边界节点 B
2. **边级内法向**：对每条自由边 (a,b)，取其所属单元的 3/4 个节点重心 G，
   垂直于边且指向 G 的方向即内法向。
   *关键：不需要给边界排环序，也不依赖 CW/CCW，天然容忍多环和开链。*
3. **节点法向** = 所属自由边法向的均值，miter 长度补偿 `1/cos(θ/2)`，限幅 `2.5W`
4. `B' = B + W × n`
5. **改写第一排单元**：把含边界节点的单元的边界顶点换成 B' 顶点
6. **填条带**：每条自由边 (a,b) → 四边形 `[a, b, b', a']`

组装时 B 收 Z0、B' 因不在界面集合里自动落 Z±0.5，washer 就自然变成
"从 Z0 张到 ±0.5 的锥面"。

### 1.4 硬约束：必须"全改"

**留一个单元用原节点都不行。** 该单元与邻居的共享边会变成
「原节点边 vs 偏移点边」一对不匹配的自由边。

cab2 实测：上版留下 4 个单元（面积比 < 0.15 的保护逻辑）→ **35 处缺口 / 69 条
假自由边**；改成强制全改后 PID3 自由边归零。

代价是少数单元会被压得很扁，交给质量统计把关，不要用"跳过"来保护。

### 1.5 cab2 实测结果

| 项 | 值 |
|---|---|
| 带宽 W | 2.5 mm |
| 条带数 | 2612（= 自由边数） |
| 覆盖面积 | 32,943 mm² |
| 宽度分布 | 中位 2.525 / min 1.881 / max 5.273（尖角 miter 处） |
| 收拢带（组装后实测） | **2.57 mm**（p10–p90 全 2.57） |
| 单元 | 全四边形，内角全 90° |
| 雅可比 | **中位 1.000** |
| 副作用 | 23 条短边 <1.5mm（最短 0.925mm，凹角偏移撞点），占气腔单元 0.03% |
| aspect | 3.30（2.5×5 的固有值，正常） |
| 覆盖位置 | 气腔外轮廓整圈 + 4 条缝线洞边界整圈 |

### 1.6 拓扑后果：界面连接口径必须同步改（踩过）

washer 夹在气腔主体与布带/缝线之间，**两侧都共节点**：

| 界面 | 共节点数（cab2 W=2.5） |
|---|---|
| washer 外圈 ∩ 布带 | 1,615 |
| washer 内圈 ∩ 气腔主体 | 2,612 |
| washer ∩ seam0/1/2/3 | 429 / 225 / 186 / 141 |

代价：**气腔与布带不再直接共用节点**（`cav∩belt` 由 1615 → 0）。
如果验收脚本仍按 `cav ∩ belt` 判断界面，会误报"界面断开 / 共节点 0"。

**改法**：所有界面检查的角色一律换成 `cav_washer`：
`cav_washer∩belt`、`seam∩cav_washer`、`cav_washer∩cav`。
`qa_cab2.py` 已按此改；`auto_gate` 用的是 K 文件全节点集合，不受影响。

### 1.7 参数

```python
W = 2.5             # 带宽 mm (主尺寸 5mm 的 50%; 参考模型 4.0mm)
MITRE_MAX = 2.5     # 尖角 miter 限幅（倍数 W）
MIN_WASHER_AREA = 0.05
```

想改宽度只改 `W`；想单拆部件，把 `assemble` 里
`pid_map["cav_washer"]` 从 3 改成 10，并补 `*PART` / `*SECTION_SHELL`。

## 2. 拉带凸台：栅格并集提取

### 2.1 为什么不能按面积阈值挑

cab2 每站凸台在 CAD 里是 **2~4 个独立闭合环**，甚至含开链：

| 环 | 面积 | 尺寸 | 位置 | 处理 |
|---|---|---|---|---|
| A 上部梯形 | 3515.2 | 82.3×80 | Y 367–447 | **必须画** |
| B 下部凸字块 | 4842.9 | 66×80 | Y 300–380 | 必须画 |
| C 内槽 | 678.6 | 36×26 | Y 310–336 | 忽略 |
| D 螺栓孔 | 271.7 | 19×18 | Y 423–441 | 忽略 |

- A 与 B 在 **Y 367–380 颈部重叠**，真实凸台 = A ∪ B
- 有的站（如第 5 站）**A 环不存在**，上部轮廓是开链（瓶颈处 1.3mm 断口）
- 只按 A/B 两个面积挑 → 7 站的**上部梯形整段丢失**（凸台上半截没网格）

### 2.2 做法

1. 按 X 把 L4 线分到 8 个站位桶（离站中心 130mm 以外的丢弃）
2. 每站所有线用 **3mm 粗笔画进 0.25mm 栅格**（粗于 CAD 断口，自动封缝）
3. 从图像四边 flood fill 标"外部"
4. **非外部**（含线墙）= 凸台；腐蚀半个线宽回到墙中线
5. Moore 邻域追踪外轮廓 → DP 简化 1.2mm

关键点：取 `~outside` 而不是"最大连通块"——A 被自己的底边线切成独立块，
取最大块会丢掉上部。

### 2.3 cab2 实测

| 站 | 面积 | Y 范围 | 轮廓点 |
|---|---|---|---|
| 1–7 | 7947.2 | 300.6–447.4 | 26 |
| 8（八边形） | 6589.3 | 324.7–455.7 | 8 |

面积自洽：7947.2 = A 3515.2 + B 4842.9 − 颈部重叠 411 ✓

网格后：2425 单元 / 62,257 mm²（只有下半块时是 1609 / 40,972）

## 2.5 侧面拉带：从布带端面缺口穿出的横向拉带

### 2.5.1 识别特征

cab2 右端（X≈1620）有一条 **横向** 拉带，形态与顶部 8 个竖直凸台完全不同：

| 项 | 值 |
|---|---|
| 走向 | 水平（沿 X），不是竖直 |
| 主体 | X 1572.4→1719.4，Y 166.8→176.3（**宽 10.2mm** 的窄长条） |
| 右端 | 眼环（Y 159.8→183.6）+ 凸销，X 1719→1771 |
| 左段 | X 1572→1620 **落在布带内部**，与布带面重叠（= 缝合区） |
| 穿出口 | 布带端面 X=1620.2 的 **20.22mm 缺口**（这条缺口本身是 L1 的一条独立线） |

**最容易踩的坑**：布带端面那条 20mm 缺口会被误判成"充气口管口/工艺孔"而忽略，
但它其实是拉带的**穿孔**。判据：缺口宽度 ≈ 拉带宽度、且该处有 L4 线穿过。

### 2.5.2 三步做法

1. **轮廓提取**：`scripts/stage2_partition/tether_side_outline.py`
   —— 同 tether_union 的栅格并集，窗口限定到该拉带 bbox；
   眼环孔、缝制纹按"细小 curve 忽略"填实。
   注意：这类拉带的 CAD 线**左段是开链**，flood fill 会漏进去，
   靠"取 `~outside` 后腐蚀半线宽"能收到正确外缘。

2. **左端对齐布带边界**（关键，否则捏合会有整体平移）：
   CAD 里 1572→1620 与布带重叠，FE 里**不要重复建面**。
   把多边形左端两点直接放到布带边界 `X = X_belt` 上，Y 取**布带边界那排节点的实测值**：

   ```python
   Y_LO, Y_HI = 159.01, 184.02      # 布带边界节点实测 (间距 5mm, 共 6 个)
   ```
   实测这一点极其重要：cab2 第一版取缺口宽 161.7~181.7，结果拉带节点与布带节点
   全部错开 2.32mm，捏合后会整体平移。改成实测值后**零位移**。

3. **生成 Tcl 划网格**：`scripts/stage2_partition/gen_side_tab.py`
   —— 与凸台同一套 `*createnode → *linecreatefromnodes → *surfacesplineonlinesloop
   → *interactiveremeshsurf → *automesh`。

### 2.5.3 连接方式（与参考模型同构）

参考模型 `5P-BAG_004.key` 实测：

| 项 | 值 |
|---|---|
| 布带 PID6 ∩ 拉带 PID7 | 164 节点 |
| 布带 PID6 ∩ 拉带 PID8 | 115 节点 |
| 气腔 ∩ 拉带 | **0** |
| 拉带厚度位置 | PID7 → Y −0.681，PID8 → Y −1.120（两块**不同深度**） |
| 根部过渡 | Y=0 与布带共节点 → **一排单元斜降** → 拉带平面 |

→ 规则就是三条：**根部与布带共节点、只连布带不连气腔、一排斜降到自己平面**。

侧面拉带照此做：左端 6 个节点共节点（Z0），其余 Z=−1。

### 2.5.4 cab2 实测

| 项 | 值 |
|---|---|
| 单元 | 93（四边形 83 / 三角 10，tri 10.8% — 眼环处不可避免） |
| 面积 | 2,266 mm² |
| 共节点 | 6（零位移，6/6 全部对齐） |
| 最短边 | 3.00 mm |

## 3. 另外两坑

### 3.1 单元法向不能用前三点叉积

凹四边形在凹角处，前三点叉积会给出**反向假信号**（cab2 的 PID5 因此误报 1 个
反向单元）。改用 **Newell 法**（全顶点求和）：

```python
nz = sum((a.x - b.x) * (a.y + b.y) for 每条边 a→b)
```

### 3.2 拉带连接点要取"整片节点"而非"边界节点"

凸台颈部与布带边界相交处，**边界上只有 2 个点**，只拿边界节点去匹配 →
每站仅 3 个共节点。改成整片节点在布带自由边走廊内找最近邻 →
每站 9 个（= 颈部一排），cab2 从 24 提到 73。

TOL 取 4mm，1-to-1 贪心，实测最大移位 2.54mm。
