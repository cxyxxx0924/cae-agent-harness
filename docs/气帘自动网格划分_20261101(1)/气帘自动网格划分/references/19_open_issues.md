## 二、该做没做（有明确方案，缺工作量）

### A1 · 侧条根部的"布带内部锚固链" ★OPEN（优先级最高）

**现状**：侧面拉带（X 1572~1771 / Y 160~184 / 2330.6mm²）根部 47.8mm 埋在布带内部，
不在布带自由边界上，`plan_anchors.py` 拿不到锚点 → 走组装阶段的"内部锚固"二次焊接
（`SNAP_INSIDE_TOL=3.0` + `WEAK_ANCHOR_MIN=1`），得到 20 个松散过渡单元。

**影响**：侧条带回 6 个 >15° 过渡单元，整体不合格 74 → 82。
**方案**：为它单独规划"布带内部锚固链"——在布带面上沿侧条根部中线切一刀，
反求该线与布带网格的交点作为锚固链，再对侧条做三刀切。
**做完预期**：不合格 82 → ~76，侧条根部错位 σ 从 3.72 降到 <0.1。

**前置**：需要布带面上有一条能"落到网格节点上"的参考线；`plan_anchors.py` 需扩展支持"内部线"输入。

### A2 · 门禁 WARN 未清零 ★OPEN（低优先）

| WARN | 实测 | 是否需要处理 |
|---|---|---|
| belt 主边界 41.51mm | 与 v3 同源，位置在充气口附近 | 需人确认该处是设计开口还是漏网格 |
| 最小边 <3mm | p99 5.39mm，少数 0.3~2.0mm（凸台顶角 + 扁平区） | 与 G2/G3 同源，接受 |

### A3 · 充气口封口口径未定 ★BLOCKED（等设计输入）

cab2 充气口在 X 616–881（约 410mm 缺口）。当前做法：气腔在该处**开口不封**。
`references/04 P45` 记录 cab1 的口径是"图纸固有开口，不封也没关系"，但 cab2 的开口形态不同，
**需要用户确认是封还是不封**。封的话要多一块面 + 与气腔上下唇捏合。

## 四、已判定不做（写清为什么，防重试）

| # | 曾尝试 | 结论 |
|---|---|---|
| X1 | 锚固边塞显式节点（方案 A：polyline / band / hybrid） | 翘曲 78~82° vs 三刀切 33°，**全面输**。根因：显式节点控制不了配对行平行（P50） |
| X2 | `*surfaceaddnodesfixed` / `*surfaceaddpointsfixed` / `*surfaceaddpoint` | HM2026 全部 r=1 或假成功，该命令族不可用 |
| X3 | 拉带先划好再整体吸附到布带 | 横向错位最多一整格 5mm，输的那个节点拉出 60~78° 扭转片（v3 实测 165.7°） |
| X4 | 三刀拆成 5mm 分段短线 | 公共端点生成两套节点，网格不连续 |
| X5 | 只横切一刀（不切竖刀） | 中间块宽 5.137mm、累积偏差 1.7mm，超吸附容差 |
| X6 | 用大 tol 硬补 CAD 缺口 | 会把相邻环串错，闭环数失真（P39） |

## 六、这份清单怎么维护

1. **每次交付报告里写的"已知残留"，必须有一条对应到这里**（不能只写在报告里）。
2. 解决一条就把状态改 `WONTFIX`/删除，并在 CHANGELOG 记一行。
3. 新发现的"能跑但对不齐"，先登记再决定做不做——**不要当场就改，会打乱回归基线**。
4. 状态为 `OPEN` 的条目，下次开工按优先级从 A1 往下挑。
