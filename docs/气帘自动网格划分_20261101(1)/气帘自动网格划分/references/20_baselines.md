> **用途**：判断"这一版对不对"。改脚本、换参数、换机器之后，跑出来的数字必须能和这里的对得上；
> 对不上不一定是坏事，但**必须能解释为什么变**。
>
> 机器可读版本：`assets/baselines.json`（供脚本比对）。
>

> 面积取自 3D 单元面积和（气腔双层按几何面积/2），不合格率取自 `mesh_quality_gate.py`。

## 5. 怎么刷新台账（做完一版交付就更新）

```bash
# 1) 出数字
python scripts/gate/mesh_quality_gate.py <deck> --pids 2,3,4,5 --out out/qgate.json
python scripts/gate/partition_cover_check.py --k <deck> --pids 2,3,4,5 --write out/ref_manifest.json
python scripts/gate/qa_kfile_strict.py <deck>
md5sum <deck>

# 2) 三个数必须人工记录（脚本不产出）：拉带连通组分个数、锚固排宽度/σ、翘曲 max
python scripts/gate/cmp_pid5.py <deck>            # 组分个数 + 逐块面积
python scripts/gate/tab_anchor_stat.py <deck>     # 锚固排宽度/错位
python scripts/gate/anchor_metric.py <deck>       # 最小角/翘曲/蝴蝶结

# 3) 把新一列加进上表，并更新 assets/baselines.json
```

> **规矩**：台账里只写**实际跑出来的数字**，不写"预期"。预期写进 runbook，
> 实测写进这里，两者对不上就是新坑，登记到 `19_open_issues.md`。

## 6. 口径警告（不写清口径的数字会误导人）

**锚固排的"过渡单元"有两个口径，差 4 倍，汇报时必须说明用哪个：**

| 工具 | 口径 | cab2 v4 实测 |
|---|---|---|
| `tab_anchor_stat.py` | 只统计**双节点**过渡单元（上下边各 ≥2 点落在锚固线上） | 99 个，宽度 5.00mm |
| `anchor_metric.py` | **宽口径**：任何与锚固线相交的单元 | 135 个，含 36 个单节点翻边 |

`>15°` 的 23 个全部在"单节点翻边"里（每块两端 + 折角，缝边翻折形态）。

**另外**：`mesh_quality_gate.py` 的最小角统计会**排除退化单元**（四点共线面积 0），
所以它的 `amin_p1 = 65.2°` 看起来比 `anchor_metric` 的 `8.3°` 好很多 ——
两者不是同一个总体，**不要混在一张表里比**。

**Y/Z 分层口径**：`auto_gate` 的分层检查**豁免跨角色界面节点**（拉带接布带可取 Y0）。
所以"Y 分层 PASS"不等于"所有节点都在标称层上"。
