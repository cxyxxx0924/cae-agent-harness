# 09 · 四分区（布带/气腔/缝线/拉带）归类方法

> 来源：2026-10-21 NEW_CAB（`Drawing0904ZHEDIETU.iges`，828 条线）实战。
> 目标：把 IGS 导入后挤在**一个 component** 里的所有 2D 曲线，按用户口述规则分成 4 类，
> 落地成 4 个 HyperMesh component（布带 BELT / 气腔 CAVITY / 缝线 SEAM / 拉带 TETHER）。

## 1. 用户口述规则（NEW_CAB，2026-10-21）

| 分区 | 视觉特征（用户原话要点） |
|---|---|
| **布带 BELT** | 最外闭环；左下右平直、转角圆弧；**上方有充气口，锐角 30–40°**；宏观连续、导数光滑，只在充气口出大转角 |
| **气腔 CAVITY** | 左/右/上贴近外环；**底部挂很多水滴**（圆头+茎连腔体边界） |
| **缝线 SEAM** | 独立的**内部**窄线 + **两头圆圈 = 哑铃状**，"两头圆圈才能封闭" |
| **拉带 TETHER** | 顶部 6–7 个凸台 + 左侧补丁/革眼 + 右侧补丁；**充气口和水滴源头不是拉带，要回归原环** |

配套铁律：几何/图形类工作**交互语言是图像**（P13）——先渲染标准底图，人在图上确认，
再落脚本；不要用"自动搜索"猜语义。

## 2. 流程（7 步）

```
① IGS 导入            import_igs_2026.tcl        → newcab.hm（828 线，1 个 comp）
② 全量几何导出        geom_query.tcl             → geom_features.txt（长/端点/切线）
                      采样点导出                 → newcab_lines_pts.txt（折线 xyz）
③ HM 原生几何辅助     hm_linelength / hm_getlinestartpoint / hm_getlinetgstartpoint /
                      hm_getlineangle / hm_getboundingbox（hmbatch 2026 可用）
④ 环链追踪            trace_full.py + bridge_scan.py
                      - 端点 2mm 焊接 + 切线连续判据（P36）
                      - 扫描"跨类搭接"候选线（TETHER↔CAVITY / TETHER↔BELT / BELT↔SEAM）
⑤ 分类修正            classify8_fix.py           → newcab_classify8.json
⑥ 渲染复核            render_v8.py（4 面板 + 总览）+ 局部 zoom（缝线左半/右缘梯子/右上凸台）
⑦ 落地 component     export_class_lists.py → make_comps.tcl → verify_partitioned.tcl
```

## 3. 关键判据（NEW_CAB 实测数字）

- **布带外环**：x[−365.2, 1620.2] y[−167.0, 497.4]；**气腔环**：x[−350.7, 1579.3] y[−152.6, 357.4]
  （布带带宽约 26mm 顶 / 14mm 底；两环**嵌套**不是互斥）
- **充气口**：领圈从布带顶边冒出，x 537–926，y 357.45→497.37；外壁 14°→28°→rim→右侧锯齿；
  内壁起点 = 气腔顶边缺口左端 (478.11, 357.45)。**气腔顶边 410mm 缺口是图纸固有**
- **凸台**：7 个城堡状，跨布带顶边，x≈ −275/−5/283/489/962/1275/1483
- **缝线哑铃**：4 条长带（端点曲率半圆）+ 充气口气道缝；端头是多段弧（P37）
- **右侧结构**：拉带梯带（双轨+锯齿缝+末端扣具，x 1572–1771）+ 矩形补丁（跨布带右缘）
- **左侧革眼**：2 个 40mm 圆 + 十字 + 弧（L820/L821/L5/L37/L825–L828）
- **v8 修正清单**（TETHER→CAVITY：L68/L66/L69/L70/L93/L95/L130/L91；
  TETHER→BELT：L762；→SEAM：L163/L205）——全部由"切线连续搭接扫描"找出，不靠肉眼

## 4. 分类修正的判据顺序（先几何后视觉）

1. **环闭合优先**：一条线若与某环切线连续（dot 判据见 P36）且端点 0 缝隙搭接 → 归该环
   （气腔底边三段 L130/L95/L93 全在 y=−152.554 直线就是这么找回的）
2. **缺口补段**：环上 <25mm 的缺口，若某游离线正好搭接两端 → 归该环（L762 布带右缘 20.22mm）
3. **区域规则**：仍在 TETHER 里的碎片按位置判（顶部凸台区/左革眼区/右补丁区）
4. **渲染复核**：每版必出 4 面板 + 总览 + 局部 zoom，**人看图确认**才进入下一步
5. **闭环 QA**：各类做端点连通分析——CAVITY 应 1 个组件（仅充气口 2 个悬挂端）；
   SEAM 各哑铃应 0 悬挂端；BELT 主环外允许充气口小区

## 6. 换项目 Checklist

- [ ] 坐标平面确认（XY 还是 XZ）——导出必须带三轴
- [ ] 端点焊接容差 2mm；切线判据按 P36（别只查 dot<−0.985）
- [ ] 水滴/充气口/共边界逐一在图上确认，不硬凑闭环
- [ ] 缝线端头查折线曲率，别把弧端当 V/方头
- [ ] 搬线用 `*movemark lines 1 <comp名>`；写盘前 `file delete -force`
- [ ] 校验用"by collector name 拿回 id 集合"与分类真值逐 id 比，不是只比条数
