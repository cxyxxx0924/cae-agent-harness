## 4. 参考模型连接拓扑（决定性结论，P22）

`ref_conn_map.py` 解析 `5P-BAG_004.key`：

```
PID8(拉带) ∩ PID6(单层布带) = 115   ← 直接节点捏合
PID8(拉带) ∩ PID7(气腔侧)   = 112
PID8(拉带) ∩ PID2(凸台帽片) = 42    ← 帽片与拉带全共节点
PID8(拉带) ∩ PID4(气腔双层) = 0     ← 拉带不连气腔双层
```

→ 拉带只连**单层布带**，靠**共节点**不靠 CNRB（P22）。本技能拉带只并到 PID2，与之一致。
