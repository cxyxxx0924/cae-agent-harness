# 17 · 拉带↔布带锚固排畸形的根因与修法

> 用户观察："拉带网格先做好再硬共节点，变得很畸形——雅可比差、大倾角"。
> 本文是 2026-11-01 在 cab2 `cab2_curtain_airbag_v3.k` 上的实测诊断，含根因、证据、修法。
> 结论：**根因是拉带面在锚固处没有一条落在布带边界上的网格边**，不是"列相位"这么笼统。

---

## 1. 现象量化

以 v3 交付件（83,637 单元 / PID5 拉带 2,621）为样本：

| 组 | 单元 | 翘曲 p50 | p95 | max | >15° |
|---|---|---|---|---|---|
| 锚固排（含布带共节点） | 186 | 1.59° | **35.92°** | **165.70°** | 53 |
| 拉带其余 | 2,435 | 0.00° | 0.00° | 0.00° | 0 |

拉带本体是平面（Z=−1），翘曲恒 0°；**问题 100% 集中在过渡这一排**。
最小内角同样：锚固排 p1=28.1°、最小 27.7°，本体 p1=41.7°。

---

## 2. 根因（两个，叠加）

### 2.1 拉带第一排**骑跨**在布带边界线两侧

截取最差单元（eid=81547，翘曲 71.9°）的四个角：

```
n0  布带 Z=0    X=  9.78   Y=382.56      ← 布带边界线 Y≈382.56
n1  拉带 Z=-1   X= 11.29   Y=379.52      ← 在边界线**下方**
n2  布带 Z=0    X= 14.78   Y=382.56
n3  拉带 Z=-1   X= 12.83   Y=383.30      ← 在边界线**上方**
```

拉带面是独立 automesh 的 5mm 网格，行是等 Y 的；布带边界在 Y≈382.56。
拉带的第 k 排在 379.52、第 k+1 排在 383.30 —— **正好一排在边界内侧、一排在边界外侧**。
吸附时两排都去找"最近的布带节点"，于是相邻列的落点一上一下交错，单元被拧成麻花。

同类：eid=81232（71.0°，376.33 / 383.14 骑跨）、eid=82405（70.1°，376.92 / 383.14 骑跨）。

### 2.2 布带侧 3 个节点挂 1 个拉带节点

eid=82421（翘曲 165.7°，直接折叠）：

```
n0  布带 Z=0  X=965.90  Y=382.57
n1  布带 Z=0  X=970.89  Y=382.56   ← 三节点共线（间距 5mm）
n2  布带 Z=0  X=975.89  Y=382.56
n3  拉带 Z=-1 X=968.75  Y=386.49   ← 只挂 1 个拉带节点
```

三点共线的四边形 = 退化单元，翘曲必然接近 180°。
成因：拉带侧节点数少于布带侧，吸附变成多对一，多出来的布带节点被"扇"进同一个单元。

### 2.3 不是 bug 的部分

- 共节点比例：本模 94/2,997 = 3.1%；参考模型 5P-BAG_004 是 164/3,868 = 4.2%。
  **"只用一排节点连接"是设计**，与参考一致，不是漏吸附。
- "锚固节点 → 拉带本体最近节点" 平面距离 p50=3.51mm：这是本体网格行与缝线行的固有错位，
  参考模型用 3mm 网格把它压到 1.5mm 以内；它本身不致命，致命的是 2.1 的骑跨。

## 3. 修法：让锚固边成为拉带网格的一条边

用户提的思路是对的：**布带网格先定，拉带网格跟着它排**。落地做法：

### 3.1 几何层（推荐，根治）

在拉带面生成阶段，用**布带边界线**把拉带面切一刀：

1. 取拉带多边形与布带边界的重叠段（锚固段）曲线
2. 用它在 Z=−1 的投影切拉带面 → 得到一条跨整宽度的 edge
3. 该 edge 的 **edge density 设为"布带锚固段节点数 − 1"**
4. automesh 后，拉带第一排节点正好落在这条 edge 上，且数量与布带锚固段一致
5. 组装时第一排 → 布带节点是**纯 Z 抬升**，横向位移 ≈ 0 → 不出麻花

对应命令（HM 2026）：
```tcl
*createmark lines 1 <锚固段线>
*createmark surfs  1 <拉带面>
*surfacemarksplitwithlines 1 2 0 13 0          ;# 切出锚固边
*createmark lines 1 <新 edge>
*setedgedensity 1 <n>                          ;# 与布带锚固段节点数一致
*automesh 0 2 2
```

**与 SCAV/SBELT 同一手法**：同一条几何边 → 共享拓扑 → 节点复用 → 0 丢失。
区别只是拉带在 Z=−1，所以几何上要先投影再切。

### 3.2 组装层（兜底，只在几何层做不到时用）

若拉带面已经被切好但数量仍不匹配，用**保序指派**代替"最近邻"：
按拉带第一排的沿边顺序，单调映射到布带锚固链的顺序（贪心 + 不允许交叉），
多出来的布带节点用三角形吸收。绝不能允许"相邻列落到非相邻布带节点"。

> 反面教材：`rebuild_anchor_band.py` 的 two-chain strip 在**已错位的拓扑上**重建，
> 只会把交叉换个位置（实测 p50 降到 0 但 max 仍 179°）。**必须先修生成，再谈重连。**

## 4. 验收判据（可直接进门禁）

| 判据 | 门限 | 现状 v3 |
|---|---|---|
| 锚固排翘曲 >15° 的单元数 | 0（或 ≤2%） | 53 / 186 = 28.5% ❌ |
| 锚固排翘曲 max | ≤ 15°（= atan(ΔZ/列距) + 余量） | 165.7° ❌ |
| 锚固排最小内角 p1 | ≥ 30° | 28.1° ❌ |
| 含 3 个共线节点的单元 | 0 | 存在 ❌ |
| 拉带第一排「骑跨」布带边界的列数 | 0 | 多 ❌ |

建议加进 `scripts/gate/mesh_quality_gate.py` 的 `--anchor` 检查项：
拉带 PID ∩ 布带 PID 的共节点邻接单元单独统计，翘曲/最小角另设门限。
