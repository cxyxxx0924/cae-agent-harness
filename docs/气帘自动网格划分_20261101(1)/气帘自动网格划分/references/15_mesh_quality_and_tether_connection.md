# 15 · 碰撞网格质量口径 + 拉带连接规范（通用，非本项目专用）

> 2026-11-01 cab2 v3 实战沉淀。回答两个通用问题：
> ① "过渡区网格歪了"到底该怎么判、怎么修；
> ② 拉带（tether）与布带（belt）的连接怎么才算"跟参考模型一致"。
> 配套工具：`scripts/gate/mesh_quality_gate.py`（通用质量门禁）。

---

## 1. 质量判据：要"方正的四边"，不要求全四边

用户原话（veteran CAE 口径）：
> 圆头过渡不必要求全部矩形，碰撞网格要求是比较正四边形，可以有些三角形过渡。

所以判据是**形状**，不是**拓扑**：

| 指标 | 合格线 | 说明 |
|---|---|---|
| 四边形最小内角 | ≥ 30°（优 ≥ 45°） | 关键。歪斜/被拉的四边形主要靠它抓 |
| 三角形最小内角 | ≥ 20° | 允许三角形过渡 |
| 长宽比 aspect | ≤ 3.0 | 细长四边不算"正四边形" |
| 雅可比 | ≥ 0.6 | 凹四边会掉到 0.3 以下 |
| 翘曲 warp | ≤ 5° | 板件基本为 0 |
| **三角形占比** | **≤ 8%** | 过渡区可以有，但不能成片 |
| 尺寸梯度 | ≤ 2.0 | 相邻单元边长比，防止忽大忽小 |

> **反例提醒**：只看"四边形占比"会骗人。cab2 纯四边形版四边形占 99.4%，却有一大片被拉长的
> 斜四边形；允许三角形后四边形降到 96.9%，但**不合格单元从 555 降到 32**。

## 2. 关键杠杆：`element_type: mixed`（一行改动，16 倍改善）

在 `*blmesh_2d2` 的 string array 里把 `element_type` 从 `quads` 改成 `mixed`：

```tcl
*createstringarray 2 "element_size: 5.0" "element_type: mixed"
*blmesh_2d2 surfs 1 1 4.0 1.0 1 2 1
```

**原因**：圆形/圆头边界（缝线孔、布带指状凸出端头）在矩形场里无法用四边形铺满，
强制 quads 会把它变成一圈**被拉长的斜四边形**（红旗状）；允许 mixed 后，网格器
改为在圆头处用一小片三角形过渡，其余区域恢复正交。

cab2 实测（气腔 952,523mm²，4 缝线洞 + 颈部窄颈）：

| | `element_type: quads` | `element_type: mixed` |
|---|---|---|
| 单元数 | 84,680 | **83,637** |
| 三角形 | 499（0.59%） | 2,624（3.14%） |
| **不合格（30°/3/0.6）** | **555（0.66%）** | **32（0.04%）** |
| 最小角 p1 / p50 | 46.9° / 85.9° | **65.2°** / 87.4° |
| aspect p95 | 2.14 | **1.31** |
| 尺寸梯度 p99 | 1.34 | **1.16** |
| 界面共节点 cav∩belt | 1615 | 1615（不变） |

局部（(1200,90) 那片圆头过渡区）：`<30°` 单元 34 → **4**，斜带完全消失。

→ **默认就用 mixed**。要更高四边形比例再考虑 quads，但必须同时看最小角。

## 3. 拉带连接：参考模型到底怎么做的

解析 `ref-Output/Model_update/5P-BAG_004.key`（**ANSA 定宽 8 列格式**，
`[eid][pid][n1..n4]` 每列 8 字符；`line.split()` 会把整行并成一个 token，必须定宽切）：

| 项 | 实测 |
|---|---|
| PID6 布带 | 10,933 节点，Y 全部 = 0（10,930 个精确 0） |
| PID7 拉带 A | 2,671 节点，15 个连通块；层 Y = 0 / −0.42 / −0.55 / −0.68 |
| PID8 拉带 B | 1,309 节点，15 块；层 Y = 0 / −0.5 / −0.62 / −1.12 |
| PID6∩PID7 / PID6∩PID8 | **164 / 115** |
| PID4 气腔 ∩ PID7 / PID8 | **0 / 0** |
| PID7∩PID8 | 112（两层拉带彼此共节点） |

**结构**（每块拉带都一样）：

```
Y=0  ─────── 一排节点（每块约 10 个），与布带【共用】= 缝线
       ↓ 一排单元斜降
Y=−0.42 / −0.55 / −0.68（或 −0.5 / −0.62 / −1.12）
       拉带本体的平面，整块挂在这一侧
```

**三个必须成立的性质**：

1. **缝线是一"排"节点，不是一个点，也不是一片面**。共节点只发生在这一排上；
   拉带其余部分在它自己的平面（离布带 0.5~1.1mm）。
2. **拉带跨过布带**：它的平面投影覆盖布带的一部分，锚固排落在布带**内部**
   （参考模型 Y=0 那 164 个节点 100% 落在布带足迹内），**不是**悬在布带外缘。
3. **拉带与气腔共节点必须 = 0**。这是硬约束，气帘靠它保证拉带不干扰气腔变形。

## 4. 通用实现（`assemble_cab2.py` 已内置，可按同构思路移植）

### 4.1 两轮锚固

```
第 1 轮（外边界近邻）: 拉带节点 -> 距布带【外自由边】节点 ≤ TOL(4mm) 的，1-to-1 贪心捏合
第 2 轮（内部锚固排）: 只对第 1 轮"没取到足够锚点"的块启用
                       该块边界节点落在布带足迹内 + 距布带内部节点 ≤ SNAP_IN(3mm)
```

**为什么要分两轮（踩过的坑）**：如果第 2 轮对所有块无条件启用，凸台会被二次焊接，
节点被推挤最多 3mm → 拉带单元最小角 p1 从 40.8° 掉到 28.4°，`<30°` 从 13 涨到 29。
按块判定（该块第 1 轮锚点数 < 8 ≈ 一排）后，p1 回到 42.0°。

### 4.2 必须排除布带-气腔界面节点

布带与气腔共节点的那些节点（cab2 有 1615 个）不能再被拉带挂上去，
否则 `tether∩cav > 0`（实测会冒出 30 个），违反第 3 条硬约束。

```python
for nid in belt_n:
    if nid in cav_n:      # 界面节点, 跳过
        continue
    ...
```

### 4.3 侧面拉带的"重叠段"不能砍（本次真实 bug）

cab2 侧面拉带 CAD 轮廓 X 1572.4 → 1771.2，其中 **1572.4~1620.2 这 47.8mm 落在布带内部**。
旧脚本判断"布带已覆盖该区，不重复建面"把这 48mm 砍掉了，导致：

- 拉带根部退到布带端面 X=1620.2，**缝接位置错了**；
- 布带-拉带重叠区（48×10mm）缺失，连接/接触位置算不准。

**正确做法**：按 CAD 全长建面；重叠段照建（拉带在 Z=−1，布带在 Z=0，不同层不冲突）；
锚固排取拉带**最靠里那一端**，与布带内部节点共节点。

修正前后：`tether∩belt` 79 → **94**（新增的是内部锚固排 17 个），
单元 93 → 196，`tether∩cav` 保持 0。

```bash
# 单文件
python scripts/gate/mesh_quality_gate.py model.k

# 指定 PID + 与参考模型并排比 + 出图出 JSON
```

**不合格率 + 按 PID 分解 + 不合格区聚类中心坐标**（拿坐标直接去 CAD 里找位置）。

## 6. 已知残留（有解释，不必强修）

- **拉带上的"扁平四边"**：6~8 个单元，三个节点严格共线（最小角 0.0°），
  但**面积正常**（14–30mm²），不是退化单元。成因是网格器在边界奇数节点处生成
  跨三点共线的四边形。硬转三角形会切断与布带的缝线连接（中间那个节点往往就是共节点），
  风险大于收益 → 保留，作为已知项记录。
- 判据取 30° 时它们会出现在 WARN 列表里，但不影响求解稳定性。
