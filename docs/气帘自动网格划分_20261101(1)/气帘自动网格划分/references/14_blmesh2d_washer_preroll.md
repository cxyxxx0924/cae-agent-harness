# 14 · 前置 Washer：HyperMesh 原生 2D 边界层 `*blmesh_2d2`

> 来源：cab2 案例（2026-11-01）。用户问"washr 能不能在分区分面阶段就提前考虑"，
> 实测结论：**能，而且不需要切几何带** —— HW 2026 有原生 2D 边界层命令，
> 在"面已建好、还没划网格"这一步直接生成贴边一圈窄元。
> 证据脚本与图：`E:/work/AI_CAB/分区训练/washer_probe/`。

---

## 1. 结论先行

| 维度 | 现方案 `add_washer.py`（网格后插排） | 新方案 `*blmesh_2d2`（网格阶段前置） |
|---|---|---|
| 带宽 | 2.5mm（4.0 会挤出一排 1mm 退化元） | **4.0mm 精确**（= 参考模型实测值） |
| 最短边（cab2 实测） | 0.925mm | **1.736mm** |
| 最小内角（cab2 实测） | 3.6° | **15.8°** |
| PID3 短边 <3mm（cab2 实测） | 18,672 | **1,892** |
| 三角形占比（cab2 实测） | 3.04% | **0.59%** |
| 雅可比 中位 | 1.000 | **0.999** |
| 内孔边界 | 需单独处理 | **自动**（孔边界同样长一圈） |
| 是否破坏原走势 | 是（改写第一排单元顶点） | **否**（全新生成，一次成型） |
| 共节点 | 天然（同一套节点） | **邻居先划则天然共用**（§4.1），否则需坐标合并 |
| 位置 | 后置，组装时插排 | 前置，HM 网格阶段 |

**一句话**：能在前面做，质量全面更好，而且只要**把 blmesh 放在相邻面之后**，
共节点问题根本不存在（cab2 实测 cav∩belt=1615 一个不丢）。

## 2. 命令

### 2.1 两个变体

```
*blmesh_2d  base_type base_mark  bl_type bl_mark  num_layers first_thickness growth_rate str_id nstr
*blmesh_2d2 base_type base_mark                  num_layers first_thickness growth_rate str_id nstr nthreads
```

- `*blmesh_2d2`：BL 长在**面的全部边界**上（最常用）
- `*blmesh_2d`：额外用 `bl_mark` 限定只在哪几条线上长 BL

### 2.2 最小可运行片段

```tcl
hm_framework loaduserprofile LsDyna Keyword971_R16.0
*elementorder 1
*setedgedensitylinkwithaspectratio -1        ;# 这两句缺一不可，否则静默出 0 单元

*createstringarray 2 {element_size: 5.0} {element_type: quads}
*createmark surfs 1 $sid
*blmesh_2d2 surfs 1 1 4.0 1.0 1 2 1
*storemeshtodatabase
```

参数含义：`1`=层数，`4.0`=首层厚度(mm)，`1.0`=增长率(不生长)，`1`=string array id，`2`=字符串个数，`1`=线程数。

**不需要 `*automesh`** —— blmesh 内部把 core 网格一起出了。

## 3. 实测数据（2026-11-01，HW 2026.0.0.27 hmbatch）

| 试件 | 结果 |
|---|---|
| 100×60 平板，core 5mm | 240 元 → **363 元**；贴边带 **4.00/4.02mm**；内部当量边长 p50 4.04 |
| 同面 first=2.0 | 369 元；贴边带 **2.00mm** |
| V 形凹口 + 窄颈轮廓 | 359 → **552 元**；最差内角 28.8°；**0 个 <25°**；J 全 1.000；最短边 1.96mm |
| 120×80 带 40×24 内孔 | **449 元**；外边界 + 孔边界**各一圈窄带**；孔四角斜切过渡正常 |

**核心事实**：first_layer_thickness 就是边界带宽度，误差 <0.05mm；内部 core 由 `element_size` 决定，
HM 会自动微调密度凑整（60mm 宽 / 5mm 理想值，实际排成 13 排 4.0mm）。

## 4. 共节点：分两种情况，别一概而论

### 4.1 情况 A（**推荐路径**）：相邻面已划网格 + 共享拓扑边 → **自动共节点，不用合并**

cab2 真实气腔（952523mm²、4 个缝线洞、颈部窄颈）实测：

```
① 缝线面 automesh → ② 布带面 automesh → ③ 气腔面 *blmesh_2d2
```

结果 **cav∩belt = 1615、cav∩seam = 981，与旧版（一次 automesh）完全一致**，
组装层"坐标合并"计数 = **0**，一个节点都不需要合。

原因：`SCAV` 与 `SBELT` 是从同一张面用 `*surfacemarksplitwithlines` 裁出来的，
**共享同一条拓扑边**；相邻面先划好网格后，blmesh 在共享边上**直接复用已有节点**。

> **铁律：blmesh 要放在相邻面之后。** 顺序反过来（blmesh 先、邻居后）就会变回情况 B。

### 4.2 情况 B：两个几何上贴合但**无共享拓扑**的面 → 坐标一致、ID 两套

合成试件（两块各自 spline 建的 100×60 面并排）实测：

| 项 | 值 |
|---|---|
| 交线上节点坐标 | **逐点完全一致**（y = 0,5,…,60，13 对 13） |
| 节点 ID | 两套 |
| 共用节点 | **0** |

### 4.3 HM 的 equivalence 在 hmbatch 下不生效

实测全部失败或空转（`*createmark nodes 1 "all"` 之后调用）：

| 命令 | 返回 | 是否合并 |
|---|---|---|
| `*equivalence 0.01` / `0.01 1 0 0 0 0 0` / `0 0.01` | r=1 | 否 |
| `*equivalence2 0.01` / `0.01 1 1 1` | r=0（假成功） | 否 |
| `*equivalencesurfaces 1 0.01` | r=1 | 否 |

→ **别在批处理里指望它**。GUI 里手动 Tool > Edges 可以；批处理走 4.4。

### 4.4 情况 B 的解法：组装层坐标合并（保险）

`assemble_cab2.py` 已内置：设 `MERGE_TOL=0.05` 即启用。按 1/tol 网格量化 + 3×3 邻域
距离复核，把气腔节点映射到最近的布带/缝线节点，并从节点表里摘掉被吞掉的 ID。
**情况 A 下它报告"合并 0 个"，留着当兜底，不影响结果。**

### 4.5 另一条路（不推荐）：同一次调用多面

实测 `*blmesh_2d2 surfs 1` 里放**两个面**直接失败（r=1，0 单元）；
`*blmesh_2d` 多面 base 同样失败。
→ **`*blmesh_2d*` 一次只能一个面**，别指望靠"同批次"自动共节点。

## 5. 接入既有流水线

`scripts/stage3_mesh/build_step1_2026.tcl` 现在的顺序是：
三面（布带/气腔/缝线）→ 一次 automesh 共享 topo edge 共节点。

改成（**顺序是关键：邻居先、气腔最后**）：

```
① 建面 / 裁切拓扑（不变）
② 缝线面        → automesh（小面先做）
③ 布带面        → automesh 5mm
④ 气腔面        → *blmesh_2d2 1 4.0   （最后做，共享边自动复用 ②③ 的节点）
⑤ Z 分层（边界那圈 Z0 / 往内一圈 Z±0.5，自然成锥面）
```

参考实现：`scripts/stage3_mesh/blmesh2d/cab2_step1_bl.tcl`（cab2 全流程，可直接套用）。

**注意 Z 分层反而更简单**：blmesh 出的是平面网格，几何边界那圈节点落在界面上 → Z0；
往内一圈 → Z±0.5。washer 就自动是"从 Z0 张到 ±0.5 的锥面"，不需要特殊处理。

## 6. 踩坑清单

| 坑 | 症状 | 解法 |
|---|---|---|
| 没设 `*elementorder 1` | automesh/blmesh 静默出 0 单元 | 开头就设，且 `*setedgedensitylinkwithaspectratio -1` 一起 |
| **blmesh 放在邻居之前** | 界面节点 ID 两套、共用 0 | **邻居先划、blmesh 最后**（§4.1），共享边自动复用 |
| 多面 mark 喂 blmesh | r=1，0 单元 | 一面一次调用 |
| 指望 `*equivalence` | 返回 0 但没合并 | 组装层坐标合并，或干脆按 §4.1 排顺序 |
| spline 建带孔面 | 内环被忽略，面积 = 外框面积 | 必须 `*surfacemarksplitwithlines <面mark> <线mark>` 切开，再删内小面 |
| 取单元节点 `nodeids` | `hm_getentityvalue elems $e nodeids 0` 返回 0 | 用 `*createmark nodes 1 "by elems" $e` + `hm_getmark` |
| `*readfile` 读 .hm | 返回 OK 但 surfs=0 | mark 类型名用 `surfaces` 而非 `surfs`；`*open` 在 2026 不存在 |
| Tcl 里做大规模节点反查诊断 | hmbatch 中途崩、`exit=1` | 别在 Tcl 里按单元遍历 4 万节点；界面统计放到 Python 组装层 |

## 7. 与旧方案的选择

- **新案子 / 可重跑 HM / 要 4.0mm 带宽与干净走势** → 用 `*blmesh_2d2`（本文），
  直接把 `scripts/stage3_mesh/blmesh2d/cab2_step1_bl.tcl` 当模板改线号即可
- **已经划完网格、不想重跑 HM** → 用 `add_washer.py`（references/13）
- 两者**不可叠加**（会把 washer 当边界再长一层）
- 参数默认：`BL_LAYER=1 BL_THICK=4.0`（与参考模型 5P-BAG_004 实测 4.00mm 一致）；
  要更薄就改 `BL_THICK`，但注意薄于 3mm 会触发规范"最小单元尺寸 >3mm"的告警
