# 07 · 拉带（tabs/tethers）网格 + 与布带节点捏合

> 气帘 7 个带凸台拉带 + 左侧 2 条长拉带（CURVE 弯条 + HORIZ 横条）的网格生成，
> 以及它们与单层布带（PID2）的连接。全部脚本在 `scripts/`：`tabs_extract.py` →
> `gen_tabs_tcl.py`(生成 `build_tabs_2026.tcl`) → hmbatch → `assemble_tabs.py`。
> 连接规则以参考模型 `5P-BAG_004.key` 的**实测连接拓扑**为准（见 §5 + `ref_conn_map.py`）。

---

## 1. 区域定义（9 块）

| tag | 类型 | 处理 |
|---|---|---|
| `tab0_up`..`tab6_up` | 凸台**上半**（帽+柱+顶） | 与 `_dn` 共享膝弦边 |
| `tab0_dn`..`tab6_dn` | 凸台**下半**（矩形） | 在 Y=-1 分层 |
| `tabc7` | 左侧 **CURVE 弯条**（沿外边界线） | 单面 |
| `tabh8` | 左侧 **HORIZ 横条**（沿外边界线） | 单面 |

拉带整体分层：Y = **-1**（凸台/拉带在折叠下方），与布带重叠段爬到 Y=0 通过节点捏合连接。

## 2. 区域提取 `tabs_extract.py`

- 输入：`out/tabs_lines_pts.txt`（曲线采样点，来自 `export_tabs.tcl`）+ 客户《图样识别规则》。
- `boss_split(r)`：肩部→膝部分割 → up = 帽+柱+穹顶，dn = 矩形；上下两片**共享"膝弦边"**节点（坐标 dedup `round 1e-4` 保证共节点）。
  - 穹顶被拆成多段短线时（BOSS3 型，cx≈1774）用**兜底**：全部高出基柱顶的源点凸包 ∪ 基柱帽，
    判据"实质性接入"= 面积 ≥1.4× 基柱帽 且顶部高出 ≥5mm，否则视为穹顶拆段走兜底。
- **HORIZ（左长横条）= 主轮廓线构造**（用户 2026-10-21 要求：啮合点在拉带末端、粘合线垂直布带长度方向）：
  1. 主轮廓线 = 区域**最长线**（L305，闭合成环）= 干净拉带体（x946.9–1105.1，z947.4–956.9）。
     CAD 右端是斜切倒角 → 末端 10mm 带补直成**竖直末端边**（垂直布带 X 向长度方向）。
  2. 其余密集装饰线（扇形接口 L195–304 + 锯齿 L308 + 缝线 L306/307 + 挂刺 L309）：
     缓冲并集 → 填洞 → **开运算 ±2 净零**。4mm 厚装饰带（锯齿/缝线/挂刺）被腐蚀掉，只剩实体扇形接口（x908–960）。
  3. ① ∪ ②（扇形接口与拉带体在 x947–959 重叠，并集自然连通）→ ≈2270mm²。
  - ⚠️ 铁律：开运算必须 **±2 净零**。旧代码 `+2/-2.5/+2.5` 净 +2 → 整体外鼓 2mm（带宽 9.5→13.5mm）。
  - ⚠️ 铁律：锯齿/缝线是**表面装饰**，绝不上轮廓（参考模型 R8 拉带体 z947–957 干净无锯齿）。
  - ⚠️ 扇形接口是 110 条密集扇贝弧的**包络近似**，其 <3mm 微锯齿在 5mm 网格下必然产出 <3mm 单元边
    （公司规范 2.2 硬条款）→ HORIZ 的 simplify 容差单独放到 **2.0**（连接关键几何是 90° 角，不受影响）。
- CURVE 直接用外边界环（cab1 的 R7 右端天然是竖直边 x1115.4，无需补直）。
- 输出：`out/tabs_polys.json`（9 区域多边形）、`out/tabs_lines_pts.txt`。
- ⚠️ **聚类偶发重复/漏区**（如 c=2531/2741/2949 重复，c=1272/1544/1774 漏出）→ 跑完务必目视 `assets/v_tabs_polys.png` 或 `render_tabs_regions.py` 复核区域完整。

## 3. Tcl 生成与批处理网格

- `gen_tabs_tcl.py` 读 `tabs_polys.json` → 写 `build_tabs_2026.tcl`：
  - 开头必写 `hm_framework loaduserprofile LsDyna Keyword971_R16.0`（P2）
  - 每块 spline 建面（`*surfacesplineonlinesloop`）
  - **逐面 automesh**（§4 P26：grouped 只 mesh 第一个面，废弃）
  - 每块导出 `T <tag> <eid> <nodes>` + `N <nid> <x> <y> <z>` 到 `out/tabs_mesh_2026.txt`
- 跑：`hmbatch.exe -tcl scripts/build_tabs_2026.tcl`
- 现状：16 面 → 3596 节点 / 3277 单元。

> 上下两片共享膝弦边：靠 HM 对同一直线**确定性离散**（同坐标 → 同 nid）+ 装配端坐标 dedup 双重保险，得到真正共节点。

## 4. 装配与连接 `assemble_tabs.py`（核心）

读 `tabs_mesh_2026.txt` + `step1_mesh_2026.txt`（布带）+ `cab1_step1_2026.k`：

1. **建节点**：拉带节点落 Y=-1。
2. **坐标完全相同节点合并**（共享弦边安全网，`round 1e-4`）。
3. **捏合 = 落到布带（PID2）节点，且只对 PID2（单层布带）**：
   - ★ **合并目标必须从目标 K 文件本身解析**（`*NODE` 坐标 + PID2 单元节点集，9222 个），
     **绝不能用导出文件 `step1_mesh_2026.txt` 的 nid**——K 写出时 gid 重编号
     （P29），两个 id 空间错位，拿 txt 的 id 合并 = 全模型飞丝。
   - 参考模型实证（P22）：拉带只连单层布带(PID6)，不连气腔双层（PID8∩PID4=0）→ 不能并到 cavity/seam。
   - TOL = 3.0mm（XZ 平面）。
4. **连接边选择**（用户 2026-10-20/21 两次修正，§5 实证）：
   - **凸台片**（`tab*_up/dn`）：并该片外周边上靠近布带、且位于**最高连接 Z 附近 8mm（EDGE_BAND）**的节点
     → 顶帽边一条水平线（平行布带长度方向）。
   - **左区长拉带**（`tabc*`/`tabh*`）：并该片外周边上靠近布带、且位于**最右端 3mm（END_BAND）**的节点
     → **末端竖边**（垂直布带长度方向）。判据 `is_left_strap(tag) = tag.startswith(("tabc","tabh"))`。
   - ⚠️ 曾错把左拉带沿**顶边**（水平，平行布带）连 → 用户否决；正确是**末端竖边**。
5. **全局 1-to-1 贪心匹配**（距离升序，每个布带节点至多被一个拉带节点复用）→
   **结构上杜绝"同一单元内两拉带节点并到同一布带节点"**，零退化丢单元（P24）。
6. **去重**：拉带单元节点集若与既有单元（belt/cavity/seam）**节点集相同（无序比对，与 QA 口径一致）** → 剔除（零厚度重合伪单元，P23）。
7. 写 `cab1_step1_2026.k`：新增 PID5 节点（Y=-1 的取新 gid）+ PID5 单元（eid 续 80464）+ `*PART` 5。

  ...

  tabh8   : 共节点  4, 连接单元  2/ 94   ← HORIZ: 末端竖边 3 共节点(唯一), x1104.4 z946.5~956.8

左区长拉带**只在末端竖边一条线共节点**（与参考模型一致），不再整个重叠区啮合。

## 5. 连接规则以参考模型实证为准（关键，P22）

`ref_conn_map.py` 解析 `5P-BAG_004.key`，得出决定性连接拓扑：

| 参考 PID | 含义 | 与拉带(PID8)共节点 |
|---|---|---|
| **PID6** | **单层布带** | **115**（拉带直接捏合到布带，重叠段爬到 Y0） |
| PID7 | 气腔侧/缝侧 | 112 |
| PID2 | 凸台帽片 | 42（帽片与拉带全共节点） |
| PID4 | 气腔双层 | **0**（拉带不连气腔双层） |

**结论**：
- 拉带↔布带靠**直接节点捏合**（115 个共节点），**不是 CNRB**（`*CONSTRAINED_NODAL_RIGID_BODY` 10000145 是布带↔气腔顶的连接，与拉带无关，曾误判）。
- 拉带只连**单层布带(PID6)**，不连气腔双层 → 本技能里拉带只并到 PID2。
- 凸台帽片(PID2)与拉带全共节点 → 本模型凸台帽已并入 PID5 up 片，拓扑一致。

> 连接验证图：`assets/v_ref_conn_map.png`（红=布带、黄=拉带、蓝=共节点散点）。

### 5.1 左区长拉带的连接拓扑（用户 2026-10-21 确认，参考模型实证）

参考模型 `5P-BAG_004.key` 左区（布带 PID6 左边界 x1059.4，长度方向≈X）：

| 参考 | 拉带体 | 连接方式 |
|---|---|---|
| R8 (PID8, z<1100) | x943–1074, Y=−0.5, z947–957 | 带体到 x≈1074 → **2 个爬坡单元** x1074→1079 把 Y 从 −0.5 抬到 0 → **末端竖边 3 个共节点**（x≈1079, z947.4/952.2/956.9） |
| R7 (PID7, z≥1100) | x977–1115, Y=−0.55 | 末端 2 排水平共节点（Z 1198/1201）嵌入布带左臂 5mm 双条间的 3mm 槽（夹层式） |

**结论（用户原话："啮合点应该在拉带的顶端，粘合线垂直于布带的长度方向"）**：
- 左拉带**只在末端一条竖边共节点**（垂直布带 X 向长度方向），不是整个重叠区。
- 本模型 R7 CAD 右端天然竖直边（x1115.4）→ END_BAND 直接选末端边；R8 CAD 右端是斜切倒角 →
  构造时补直成竖直边（x1105.1），落到布带 x1104.4 节点列 → 3 共节点 x1104.4 z946.5/951.7/956.8。
- 凸台（上方 7 片）用户确认无问题：顶帽边一条水平线共节点（平行布带长度方向）。
