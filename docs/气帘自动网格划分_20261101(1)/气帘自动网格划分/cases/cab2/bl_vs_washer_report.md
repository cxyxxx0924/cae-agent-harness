---

## 1. 一句话结论

把 washer 从"网格后插排"改成"划网格时一次成型"，**带宽一步到位做到参考模型的 4.00mm**，
且不碰原网格任何一行。三角形降 5 倍、气腔最短边翻倍、短边（<3mm）降 10 倍，
**界面共节点一个不丢**（cav∩belt 仍是 1615）。门禁结论与旧版持平（WARN / FAIL 0）。

## 2. 做法差异

| | 旧：`add_washer.py` 后插排 | 新：`*blmesh_2d2` 前置 |
|---|---|---|
| 时机 | 网格划完后，在 Python 里找自由边、偏移、填一圈 | 面建好、**还没划网格**时，HM 一次生成边界层+核心 |
| 气腔生成 | `*automesh` 5mm 匀网格 | `*blmesh_2d2 surfs 1 1 4.0 1.0 1 2 1` |
| 对原网格的影响 | 改写第一排单元顶点 → 走势被拽歪 | **零改动**，全新生成 |
| 带宽 | 只能 2.5mm（4.0 会挤出一排 1mm 退化元） | **4.0mm 精确** |
| 内孔 | 需单独处理 | 孔边界**自动**长一圈 |
| 关键顺序 | — | **缝线 → 布带 → 气腔**（邻居先划，共享边自动复用节点） |

改动的只有 `cab2_step1.tcl` 里气腔那一行（→ `cab2_step1_bl.tcl`），其余裁切拓扑完全不变，
所以两版可以直接并排比。

## 4. 为什么共节点没丢（上一轮预判失准，已更正）

上一轮在合成试件上测出"blmesh 与相邻面各生一套节点，共用 0"，因此预判必须做坐标合并。
**真实 cab2 上不需要**：`SCAV` 与 `SBELT` 是从同一张面用 `*surfacemarksplitwithlines`
裁出来的，**共享同一条拓扑边**；只要相邻面先划好网格，blmesh 在共享边上直接复用已有节点。

实测：组装层坐标合并计数 = **0**，而 cav∩belt 仍是 1615、cav∩seam 仍是 981，
与旧版逐项相等。

→ 铁律记进技能了：**blmesh 要放在相邻面之后**。顺序反了才会回到"两套 ID"。
组装层的坐标合并（`MERGE_TOL=0.05`）保留当兜底，报告合并 0 个即代表顺序正确。
