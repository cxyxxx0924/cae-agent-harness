## 1. 时间步长（规范 6.1，症状六"时间步长太小"）

- **计算时间由时间步长控制，不是靠 ENDTIM 硬扛**。
- `*CONTROL_TIMESTEP` 的 `DT2MS` 取负值 = 目标最小时间步长；步数 ≈ ENDTIM / |DT2MS|。
- **禁止把 DT2MS 置 0 裸跑**（退化成由最坏单元决定，实测 dt 崩到 1.57E-8、算不完）。
- 标准卡：`DTINIT 7.0E-4 / TSSFAC 0.7 / ISDO 0 / TSLIMT 0.0 / DT2MS -7.0E-4`；
  气帘项目随参考取 `TSSFAC 0.9 / DT2MS -5.5E-4`。
- 症状"时间步长太小"：① 试运行关质量缩放查时间步长信息；② 查材料单位制。

## 2. 质量缩放门禁（规范 6.2）

- 2 步试运行看 `glstat` mass scaling + `matsum` 各部件：
  **质量增加必须 < 3%**；超标的部件查网格质量（特征长度太小）与材料 E、ρ。

## 3. 网格硬条款（规范 2.2 第 5/6/7/9 条）

- 法向一致、每部件无自由边（充气口/外轮廓合法自由边除外）、part 间无初始穿透、
  **禁止重复单元与重复节点**、**最小单元尺寸 > 3mm**。

## 5. 单位制提醒（气帘项目）

- 长度 mm、时间 ms、质量 kg、压力 kg/(mm·ms²)；1 bar = 1e-4 kg/(mm·ms²)。
- 气体常数 R=287（mm·ms 单位），理想气体 P = m·R·T / V 用于 abstat 自洽校验。
- 速度单位 mm/ms（= m/s，数值同）；动能 KE = ½·M·v²，M 用织物总质量（NEW_CAB ≈ 0.70067 kg）。
