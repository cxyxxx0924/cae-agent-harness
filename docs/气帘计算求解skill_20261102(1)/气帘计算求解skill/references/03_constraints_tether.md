# 03 · 约束 / 拉带固定 / 锚点

> 用户原话："参考模型拉带上面应该是有固定的，我们这边几个拉带都没有固定，要固定一下，重新算一下。"
> 本文件沉淀"加约束"的全流程——**含一个反直觉发现：参考模型其实没固定**。

## 1. 用户决策：14 个扇形拉带自由端全部固定

- NEW_CAB 有 14 个扇形拉带（TETHER），每个自由端一组节点需钉死。
- 实现：`*SET_NODE_LIST`（sid 900010–900023，共 14 组，每组 21–31 节点，合计 336 节点）
  + `*CONSTRAINED_NODAL_RIGID_BODY`（15 个：900001 主锚 + 900010–900023）
  + `*BOUNDARY_SPC_SET`（固定 6 自由度）。
- 主锚 `900001` = 1464 节点（布带与车身连接点）；拉带固定端 = 336 节点。
- **实测固定节点合计 1800 = rbdout / spcforc 报告口径一致**（解析器漏跳 sid 行会虚高到 1816/1830，修正 skip 逻辑后确证 1800）。

## 2. 固定生效的"双证"（缺一不可）

| 证据 | 方法 | 结果 |
|---|---|---|
| ① rbdout | 15 个 nodal rigid body 在**全部 201 个输出时刻**位移/速度严格为 0 | 全 0 |
| ② d3plot 逐位校验 | 1800 个固定节点"当前坐标 vs 初始坐标" max\|Δ\| | **0.000e+00**（比特级） |

- **spcforc 是假象**：文件 67MB（旧轮 46MB），报告 1800 节点恰为固定节点，但**全部反力为 0、setid=0**。
  判定为本版本对 `CNRB + BOUNDARY_SPC_SET` 组合的输出口径问题（不写反力）。
  **固定效果必须由 rbdout 零位移 + d3plot 逐位不动独立证实**，不能信 spcforc。

## 4. 锚点布置陷阱（本会话漂移根因）

- **主锚 1464 个节点全部聚在右端** x∈[1600,1771]（布带右侧边）；
  14 组拉带固定端 336 节点分布在 **z≈305 / z≈442 两条线**上、y=-1 层。
- 锚系只箍住右端 + 两条拉带线，**质心未完全约束** → 拉带端钉死后产生持续 +z 净力，
  把袋体拉向固定端（详见 references/04 漂移诊断）。
- 这是**锚点布置问题，不是数值问题**。要压漂移：补左端布带锚点，或把拉带固定端改接到布带环（真实锚点形式）。

## 5. 加约束的标准做法（复用参考模型）

1. 从参考 deck 提取约束卡（grep `^\\*BOUNDARY` / `^\\*CONSTRAINED`），核对关键字年代（R11+ 本机拒）。
2. 本模型节点 id 与参考不同 → **用几何坐标匹配**选节点：渲染标准底图 → 用户在图上点选/描线 →
   按像素差分+坐标变换选中（用户铁律：几何/图形工作用图像交互，**不要自动搜索猜语义**）。
3. 写 `*SET_NODE_LIST` + `*CONSTRAINED_NODAL_RIGID_BODY` + `*BOUNDARY_SPC_SET`，
   三件套 sid 连续、注释清楚。
4. 提交求解后，**先验证固定生效**（rbdout 零位移 + d3plot 逐位校验），再谈其他结论。

## 6. 关键坑位

- **解析 SET_NODE_LIST 必须跳过 sid 行**：sid 行本身是 `900010,0,0,0,0.` 这种，
  若当数据读入会多加 15 个 sid 号 + 节点 0，固定节点虚高到 1830。正确 skip：先读 sid，再读数据行。
- **CNRB + SPC 组合 spcforc 不报反力** → 别用 spcforc 判固定，用 rbdout + d3plot。
- **固定节点判据 = 当前坐标逐位==初始坐标**（d3plot 状态下 max|Δ|=0.0），这是唯一硬判据。
