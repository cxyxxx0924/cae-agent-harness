## 0. 一句话结论

**抖动不是"抄错了"，而是抄对了但模型条件不同**：参考 deck 的 `MAT_DAMPER_VISCOUS C=0.2` 在参考模型上稳定，
是因为参考模型的节点质量够大；本模型的拉带锚点是纯网格节点，质量只有 **0.0075 g**（part 总质量 ÷ 节点数反算，见 §12.5），
显式积分的稳定条件 `C < 2m/dt`（临界阻尼 `C_crit≈0.030`）被压过去 **6.6 倍** → 阻尼器每步过冲 → 能量注入 → 抖动。
**解法 = 补锚点质量**（`*ELEMENT_MASS` **每点 1 g**），一个参考卡参数都不动。

## 1. P-S49（★★★ 方法论铁律）"完全参考"= 卡片参数不可动，要动只能动"模型条件"

用户的原话是硬约束，不是修辞：

> "我要的就是所有设置跟参考模型完全一样。"

**被否决的做法**：把 `C` 从 0.2 压到 0.010（抖动确实消失，但等于偷偷换了物理参数）——
症状被遮住，deck 与参考不再可比，后续所有结论失去基准。

**正确的推理顺序**（下次遇到任何"抄对了却不正常"都按这个走）：

| 步 | 问题 | 本此答案 |
|---|---|---|
| 1 | 卡真的抄对了吗？ | 逐卡 diff：10 张 `*CONTROL_*`、`MAT_NULL/FABRIC/RIGID`、接触 33 字段——只有 SSID 该不同 |
| 2 | 抄对了为什么行为不同？ | **模型条件不同**：参考锚点有质量/不同网格；本模型锚点是裸网格节点 |
| 3 | 哪条物理约束被破坏？ | 显式阻尼稳定条件 `C < 2m/dt` |
| 4 | 改什么能恢复约束而不动参考参数？ | 补质量（`*ELEMENT_MASS`）——参考卡原样保留 |

**判据**：任何"改参考值让症状消失"的方案，必须先证明"参考值在本模型上物理不可用"，
并且给出**不动参考参数**的替代解。给不出，就是遮症状。

## 2. P-S50（★★★）`MAT_DAMPER_VISCOUS` 显式失稳判据 `C < 2m/dt`

### 2.1 判据

离散阻尼力 `F = C·v`，显式中心差分下节点速度更新 `v_{n+1/2} = v_{n-1/2} + (F/m)·dt`。
阻尼项自身的稳定条件：

```
C  <  2·m / dt          ← 单自由度临界阻尼的显式稳定极限
```

超过 → 每步速度反号且幅值放大 → **能量被数值注入** → 表现为肉眼可见的高频抖动，
但 glstat 全局看起来"健康"（质量不增、沙漏不增、车身不动）。

### 2.2 本例数字（可直接照抄核算方式）

| 量 | 值 | 来源 |
|---|---|---|
| 稳定时间步 `dt` | `4.95E-04 ms` | glstat / d3hsp（DT2MS=-5.5E-4 起的步） |
| 拉带锚点质量 `m` | **`0.0075 g`**（`7.5E-06` kg） | **part 总质量 `0.7001 kg` ÷ 节点数 `93342`**。⚠️ 不要用 `面积/4 × T1 × rho`（高估 3000 倍，见 §12.5/P-S74） |
| 临界阻尼 `C_crit = 2m/dt` | **`0.0303`** | 计算 |
| 参考 `C` | `0.2` | `MAT_DAMPER_VISCOUS` MID=2400002 |
| 超临界倍数 | **6.6 倍** | `0.2 / 0.0303` |
| 补偿后 `m` | **`1.0E-3` tonne = 1 g**（每点固定增量） | `ANCHOR_MASS_ADD` |
| 补偿后 `C_crit` | `4.07` → 裕度 **20 倍** | `2×1.0E-3/4.95E-4` |

> **实测印证**：补 1 g 后 `spring&damper energy` 在 t=0.1 ms 从 `1.98E+05` 降到 `2.25E-05`（小 12 个数量级），
> `added mass` 0，`dt` 恢复 `6.45E-04`。10 点合计 10 g，占气帘总质量 1.4%，不影响动力学。
>
> ⚠️ **本文早期版本写的是"24.4~42.4 g / 补到 120 g"，那是按单元面积手算的错值**（比真值大 3000 倍，
> 会把锚点人为加重 120 倍而扭曲局部动力学）。现行值以本节与 §12.5 为准。

### 2.2.1 P-S57（★）节点质量估算必须用 `SECTION_SHELL` 厚度，不能用"裸布厚度"

项目里早期用 **0.3mm**（裸布）估节点质量 → 算出 `6.7~12.7 g`，比真值小 **3 倍**
（section 卡 T1=1.0mm，含涂层等效厚度，求解器按它算面密度）。

后果不是"结论错"（两种算法都判 FAIL），而是**裕度算错**：
- 用 0.3mm：`C_crit = 0.027~0.051` → 看起来"C 超 4~7 倍"（像严重失稳，容易误判成别的问题）；
- 用 1.0mm：`C_crit = 0.098~0.171` → 实际"C 刚超 1.2~2.0 倍"，与实测阈值严丝合缝。

**铁律**：任何"节点质量/面密度"估算，厚度一律取 `*SECTION_SHELL` 的 T1（`damper_mass_gate.py` 已按此实现）；
裸布厚度只用于成型/几何讨论，不用于动力学质量。

### 2.3 C 扫描证据（这是"根因"而不是"相关"）

同一 deck 只改 `C`，3ms 段最大动能：

| C | KE 峰值 | 判读 |
|---|---|---|
| 0.20（参考值） | **572** | 数值爆掉 |
| 0.10 | `1.1E-04` | 健康 |

**跨 5 个数量级**。这种断层式响应是显式失稳的典型指纹：阈值以上指数增长，阈值以下完全安静
（不是"阻尼大小影响抖动幅度"那种平缓关系）。

### 2.4 排除链条（为什么不是别的）

诊断必须能回答"为什么不是 X"，本次逐条排除：

| 嫌疑 | 排除证据 |
|---|---|
| 缆绳 `MAT_CABLE_DISCRETE_BEAM` EA | EA=1E10 与参考一致；改成刚性连接抖动照旧 |
| 接触 | 单面接触 33 字段仅 SSID 不同；把腔体剔出接触集（P-S48）仍抖 |
| 气囊卡/曲线/part set | 整块照抄参考 `*AIRBAG_LOAD_CURVE_ID`；曲线 21 全程近零压 |
| RefGeom | 4 字段正确（P-S41）；去掉后抖动仍在 |
| 能量归属 | **matsum / 内能分解：spring+damper 占内能 99.3%** ← 决定性证据 |
| 是否阻尼器本身 | 去掉 discrete 单元 → 抖动消失（但拉带就没了，只做定位不做方案） |

**关键一步是能量分解**：全局健康 + 内能 99.3% 集中在弹簧/阻尼 → 直接把嫌疑人从"整个模型"缩到"那 10 个阻尼器"。

## 3. P-S51（解法）补锚点质量：`*ELEMENT_MASS` 每点 1 g（早期写的 120 g 已作废，见 §12.5）

不改参考卡片，只在 `Spring_swap.k` 末尾追加：

```
*ELEMENT_MASS
$#   eid       nid                 mass
25000001,30112068,1.13281E-04
25000002,30112567,1.12034E-04
...
```

- `mass` 填的是 **增量**（`target - 现有`），不是总质量：
  ```python
  add.append('%d,%d,%.5E' % (25000001 + k, nid, max(ANCHOR_MASS_TARGET - cur, 0.0)))
  ```
  本例增量 `1.07E-04 ~ 1.13E-04` tonne/点（≈110 g/点），10 点合计 `≈1.1 kg`。
- 只在气帘侧 10 个拉绳起点节点上加（9 拉带 + 1 充气口上端），车身侧锚点在刚体 part 里，质量足够。
- 200ms 实测 `added mass = 1.499E-03` tonne（1.5 kg），占整车 **`0.023%`** —— 远低于 3% 门禁。
- **保守效应（可接受）**：若生成器用低估质量（P-S57）算增量，补偿后的**总**质量会比 120 g 略高
  （≈134~150 g）→ `C_crit` 0.54~0.61，裕度只增不减，方向安全。
- **副作用评估**：加在锚点上会略微改变拉带端点惯性（对气帘整体响应可忽略，因锚点位于布带端部且被缆绳约束）。

### 3.1 效果（3ms 对照）

| 指标 | 修复前 | 修复后（方案 A） | 参考模型 |
|---|---|---|---|
| 首帧抖动幅值 | 46.6 mm | **1.3 mm** | — |
| 3ms 最大 KE | 572 | **5.70E-03** | 1.16E-02（本模型为参考的 0.49 倍） |
| added mass | 爆 | 正常 | 正常 |

### 3.2 方案取舍（为什么选补质量，不选降 C）

| 方案 | 动了参考参数？ | 抖动 | 与参考可比性 | 结论 |
|---|---|---|---|---|
| A：补锚点质量 | ❌ 一个没动 | 消失 | 保持 | **采用** |
| B：C 降到 0.010 | ✅ 动了 | 消失 | 破坏 | 否决（遮症状） |
| C：换 `*MAT_DAMPER_NONLINEAR_VISCOUS` | ✅ 换了类型 | — | 破坏 | 否决 |

## 4. P-S52（★）`*ELEMENT_MASS` 必须用逗号格式，8+8 定宽会粘连

写成定宽 8 字符字段（`%8d%8d%8.5E`）时 `eid`(8) 与 `nid`(8) 无分隔符直接拼成 16 位数字，
R10.1 按 8 字符切仍能读，但只要有一列超宽（nid 是 8 位 `30112068` 正好顶满）就错位。

**正确**：`%d,%d,%.5E` 逗号自由格式（与 P-S03 同源）。

## 5. P-S53（★）气囊卡整块照抄，不在生成器里重映射曲线 ID

生成器早期版本会解析参考 `*AIRBAG_*` 的 LCID 再替换成本模型的曲线号 —— 引入大量不确定性
（曲线 ID 撞车、多行定宽错列、`*AIRBAG_LOAD_CURVE` 与 `*AIRBAG_HYBRID` 混用）。

**改为常量整块照抄**（本次最终态）：`REF_AIRBAG_CARD` 原样写入 `cab1_clean.k`：

```
*AIRBAG_LOAD_CURVE_ID
$  SID  SIDTYP  RBID  ...
         1       1     3      21
```

- 曲线 21 = Pressure vs time：`0→0, 100→1E-5, 200→1E-5` MPa（**全程近零压**，压力由 CV 气体驱动，不由曲线驱动）。
- SENSOR 6002 `TIME GT 100.0` 打开 AIRBAG 1；6003 `initstt=OFF`。
- `*SET_PART_LIST 1 = {4,10}`（参考织物件）；本模型 `set 1 = {3} = CAB1_CAVITY`（71208 单元主腔面）。

**教训**：凡是"参考能跑、我们只是换了几何"的卡，**整块搬**比"解析+重映射"可靠得多；
重映射只在 ID 必然冲突（跨模型合并）时才做，且必须定宽原位替换（P-S20）。

## 7. P-S55（★）质量缩放读数：`2.29E-02` 是 0.023%，不是 2.30%

`glstat` 的 added mass 是**百分比数值**，`2.29E-02` 已经是百分数（0.0229%），
不要再 ×100 或读成 "2.29e-2 = 2.3%"。

- 正确读法：`2.29E-02` → **0.023%**；门禁 3% → 相当于 `3.0E+00`。
- 本次 200ms 末值 `added mass = 1.499E-03` tonne；相对总质量 `≈0.023%`。
- 教训：**同一份日志里既有绝对质量（tonne）又有百分比**，读之前先确认这行是哪一个。

### 11.1 P-S58（★★★）`*ELEMENT_BEAM` / `*ELEMENT_DISCRETE` 只能用定宽，不能用逗号

### 11.8 P-S65（★★★）`k_health_gate.py` 的"能量比"会误判：必须把滑移能算进去

200 ms 组合算跑完，门禁报 `[FAIL] 能量比 (IE+KE)/EW = 0.92730`，但求解器自己打印的是
`total energy / initial energy = 1.00030`。

原因：`glstat` 里 **`sliding interface energy` 是独立累加项**，不并入 `internal energy`：

```
internal 404.16 + kinetic 5.25 + sliding 32.23 = 441.64   ≈  external work 441.51
```

`(IE+KE)/EW` 天然少一块，只要接触在做功（本模型 7.3%）就一定 FAIL。
- **正确判据**：读 `glstat` 的 `total energy / initial energy`（LS-DYNA 自带），或手算 `(IE+KE+SLIDE)/EW`。
- 看到这条 FAIL 先看滑移能量级，别去改模型。

### 11.9 P-S66（★★）先定单位制，再谈"压力/能量"绝对值

| 量 | 单位 | 换算 |
|---|---|---|
| 长度 / 质量 / 时间 | mm / kg / ms | — |
| 能量 | **J** | 直接读 |
| 应力、气压 | **GPa** | `1.0E-5` GPa = 10 kPa = 0.1 bar |

验证链：气腔容积 `4.90E7 mm³ = 49.0 L`（`abstat.volume`），压力 `1.0E-5` GPa →
`pV ≈ 490 J`，与 `glstat` 内能 404 J 同量级 ✔。**别按 tonne 去读，会把 0.1 bar 读成 100 bar。**

### 11.10 P-S67（★★）`*AIRBAG_LOAD_CURVE_ID` 是"压力曲线袋"，没有气体 CV

### 12.1 P-S68（★★★）拉带锚点必须取"凸台顶面"，不能取根部

气帘的拉带是一排**凸台**（tether tab），从布带主体上沿再往上凸 100~150 mm。
锚点必须落在**凸台顶面**，否则绳子会整体跨过凸台、把凸台留在约束之外：

| 位置 | 现象 |
|---|---|
| 取凸台**根部**（布带上沿） | 绳子从主体上沿斜飞出去，凸台自由翻卷 → 气帘扭转成螺旋，且"只有充气口和一端在动" |
| 取凸台**顶面**（正确） | 绳从凸台顶连到车顶梁，凸台被压住，气帘平整 |

参考模型的佐证：`5P-BAG_005` 的 7 个锚点 `Z=1243~1263`，气帘顶 `Z=1336.6` ——
锚点落在凸台上半段，**不是**布带上沿（那样会在 1164 附近）。

识别代码（`gen_main.py`）：
```python
zs = [bag_nodes[n][2] for n in ns]
if max(zs) - min(zs) >= 20.0:                  # 凸台
    tip = [n for n in ns if bag_nodes[n][2] >= max(zs) - 3.0]   # 取顶面
else:                                          # 扁平侧向拉带
    tip = [n for n in ns if bag_nodes[n][0] >= max_x - 4.0]

### 12.2 P-S69/P-S73（★★★）绳长有硬下限 95 mm，否则 dt 掉进质量缩放区

### 12.4 P-S71（★★★）`MAT_CABLE_DISCRETE_BEAM` 是 **E=0 的恒力索**，不是弹簧

卡片 `2400001 7.8E-6 0. 0 0.4 1.E10 10. 0` 看着像"E=1E10 的超硬弹簧"，实际求解器回显是：

initial tensile force ............ = 4.00000E-01      ← 0.4 N 预张力
ramp time for preload ............ = 1.00000E+01
end time for preload application . = 1.00000E+10      ← 1E10 是"预张力终止时间"，不是模量

### 12.5 P-S74（★★★）**纠正 P-S50/P-S51 的质量数字**：真实节点质量 0.0075 g，补 1 g 就够

### 13.2 P-S78（★★★）`*MAT_RIGID` 的 CMO/CON1/CON2 决定刚体是否被钉死

`MAT.K` 里 `*MAT_RIGID 2010 7.85E-6 210. 0.3 0. 0. 0. / 1.0 7. 7.`
→ `CMO=1.0, CON1=7, CON2=7`，即**全部平动 + 全部转动自由度被约束，刚体固定不动**。

后果：`*LOAD_BODY_Z` 只推动气帘，车身是墙；10 根绳的 0.4 N 预张力全变成"往车顶收气帘"的驱动力。
本轮实测：车身 10 个节点 dZ 精确为 0，气帘顶部被以 0.19 mm/ms²（≈19 g）持续上拽。

**要"整体一起上升"必须把 CON1/CON2 改成 0**，或者别指望刚体跟着 LOAD_BODY 走。
改之前先确认参考模型是哪种意图——参考 Vehicle.k 的刚体同样是 `1.0 7.0 7.0`，说明**参考本身就把车身当固定台架**。

### 13.3 P-S79（★★）`MAT_CABLE_DISCRETE_BEAM` E=0 + F0 是"恒力绞盘"

它不会像弹簧那样"拉直就停"，而是永远以 F0 收缩。所以：
- 绳长要够（≥95 mm），否则 dt 崩；
- 只要车身固定，气帘就会被无休止地收上去 → 上升段抖动、拉带节点先动、主体后动；
- 想让它"只保持张紧"就把 F0 调到 1E-3 量级，或改 `*MAT_SPRING_ELASTIC` + 小刚度。

### 13.4 P-S80（★★）三件套快速定位能量异常

```
glstat: spring&damper 暴涨 + added mass >1 kg + dt 被钳到 4.95E-4   -> 绳系统问题
matsum: 逐材料 IE                                                   -> 一眼看出是 2400001/2400002
d3hsp: "applicable degrees of freedom = 0" 表示离散单元走平动 DOF（正常）
       "initial tensile force = 4.0E-01"   说明 F0 真的生效了

`matsum` 的读法：`ie` 形状是 `(nstate, nmat)`，`ids` 给出列对应的材料号，
**不要写成 `ie[imat]`**（那是第 imat 个时刻）。

### 13.6 P-S82（★★）定宽卡片的字段序（写解析器必踩）

| 卡片 | 字段 | 解析 |
|---|---|---|
| `*ELEMENT_BEAM` / `*ELEMENT_DISCRETE` | eid, pid, n1, n2, n3 | **8 字符定宽**：`[0:8] [8:16] [16:24] [24:32]` |
| `*ELEMENT_SHELL`（自由格式） | eid, pid, n1..n4 | 逗号切分后 **`s[2:6]`**，`s[1]` 是 pid |
| `*NODE` | nid, x, y, z | `s[0:4]` |

用 `s[1:5]` 取 shell 节点会把 pid 当节点号 → 所有单元静默丢失（`segb 0`），且**不报错**。

### 13.7 P-S83（★）参考模型拉带绳的真相：只有 3 根连到真实气帘节点

`Spring_move.k` 的 10 根 BEAM 里：
- 3 根连真实气帘节点：`10092372`、`10693969`、`10065865`
- 7 根连 **node 1~7**（这些编号在任何网格文件里都不存在）

工作模型不要照抄这点，**10 根全部连到真实拉带凸台顶面节点**（本轮已这样做）。
连到不存在节点的绳在 LS-DYNA 里不会报错，会静默变成两个自由节点，白算。

### 13.8 P-S84（★）`*AIRBAG_REFERENCE_GEOMETRY` 两种记录格式

| 来源 | 每条记录 |
|---|---|
| 参考 `6P_CAB_update2.k` | `nid, x, y, z, 0, 0`（6 字段） |
| 本轮生成 | `nid, x, y, z`（4 字段） |

R10.1 两者都接受，d3hsp 会回显 `*AIRBAG_REFERENCE_GEOMETRY - 4 fields per record`。
记录数必须等于气帘节点数（本轮 82081），少一条就会有一条节点没有参考坐标 → 压力按变形后坐标算，气帘会"越吹越小"。
