# 法规条文：C-NCAP 附录G G.14.3 侧面气帘、头胸一体式气囊展开性能评估

> 来源：附录G《可变形移动壁障侧面碰撞测试评价规程》第 26–29 页（印刷页 25–28）。
> 下列为条文要点与图 G.3 / G.4 的尺寸链；正式判定以发布文本为准。

## 罚分框架
- 三项：**外观尺寸、展开形态、动态保护**；不符合分别罚分（表 G.14）。
- 外观尺寸、展开形态各罚 1 分，动态保护罚 1 分；**该项评价最高罚 3 分**。
- 展开形态、动态保护在**撞击侧**判定；外观尺寸在**非撞击侧**判定。
- 两侧不对称时单独评价，按差评原则做最终评定。
- **侧碰总体罚分上限 4 分**（含车门开启、约束系统失效等其它总体项）。

## G.14.3.1 外观尺寸（非撞击侧）
- 气帘应覆盖前排至第三排（如有）；第三排可拆卸/折叠且不适合成人乘坐时，只要求覆盖到第二排。
- **G.14.3.1.1.1** 覆盖各排评估区域（侧围顶部、B 柱、C 柱、门腰线对应区域除外）。
- **G.14.3.1.1.2** 评估区域为**圆角四边形**，四个圆角的圆心由假人头部重心（CoG）坐标确定（图 G.3）。
- **G.14.3.1.1.3** 头部 CoG 相对 50 百分位假人 H 点定义（图 G.4）：
  - 前排 5th 女性：X = H(X) + 126 − 座椅行程；Z = H(Z) + 594
  - 前排 95th 男性：X = H(X) + 147 + 座椅行程；Z = H(Z) + 693
  - 二/三排 5th 女性（最前位）：Z = H(Z) + 594
  - 二/三排 95th 男性（最后位）：Z = H(Z) + 693
- **G.14.3.1.3 缝线区域**（静态展开，袋内 **0.1–0.4 bar 或厂家推荐值**）：
  - a) 充气区域之间的**接缝宽度 ≤ 15 mm**
  - b) **非充气区域直径 ≤ 50 mm**，或**等效面积 ≤ 625π mm²（≈1963.5 mm²）**

- 圆角会切掉四角，覆盖率用矩形近似会高估约 2–4 个百分点，判边界条件时要用圆角判据。

### 图 G.4 头部重心定义
- `594 / 693` 是 H 点到 5% / 95% 头部 CoG 的**垂向距离**（图上两条水平虚线）。
- `L1 / L2 = 126 / 147` 是**纵向偏置**，对应正文公式里的 ±126 / ±147；座椅行程把座椅前后位置折算到 CoG。

## G.14.3.2 展开形态（撞击侧）
- **G.14.3.2.1** 不应出现**钩挂、破裂、卡位**。
- **G.14.3.2.2** 内饰件脱落/断裂后，不应产生**锐边、尖角、毛刺**等伤及乘员的特征。
- **G.14.3.2.3** 不应出现**硬质飞溅物**；软质飞溅物（立柱间隔泡块等）**单片 ≤ 3 g、总量 ≤ 5 g**。

## G.14.3.3 动态保护（撞击侧）
碰撞过程中，前排或第二排假人头部**接触位置应落在充气区域内**（缝线区仍须满足 G.14.3.1.3），**且不应发生"硬"接触或"触底"**。

拆成三个必须同时成立的子条件：
1. 落点在充气区（不是缝线带、不是袋外）；
2. 接触时刻的缝线区仍满足 15 / 50；
3. 无硬接触、无触底。

## 条文里的隐藏条件（判定时最容易漏）
1. **15 / 50 的测量条件是静态展开 + 0.1–0.4 bar**，不是碰撞过程中的瞬态。所以它们首先是**几何/制造判据**，用 CAD 平铺图或静态充气模型判最稳。
2. **统计范围限定在评估区域内**——区域外的宽缝线不算罚分，但区域内的一条就够罚。
3. **"充气区域之间"** 这个限定意味着气帘边缘的封边带不受 15 mm 约束（它不在两腔之间）。
4. **等效面积与直径二选一**：不规则不充气斑按面积判，圆形按直径判，两者不要叠加使用。
