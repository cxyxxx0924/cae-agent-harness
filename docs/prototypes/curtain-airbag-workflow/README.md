# 气帘仿真工作流界面原型

基于当前 CAE Agent 三栏布局的 HTML 交互原型，用于评审气帘仿真流程中的输入、工具执行、产物预览和用户确认。消息输入统一放在左侧对话区，右侧展示当前阶段、结果、文件列表和执行记录。

正式应用的窗口缩放、侧栏折叠和小屏布局沿用 dsh 默认行为，不单独设计或实现响应式布局。原型中的静态布局仅用于流程和交互评审。

## 预览方式

直接用浏览器打开 [index.html](index.html)，通过缩略图进入各阶段页面。阶段页面顶部的“上一步 / 下一步”用于切换设计预览，页面内部的确认按钮用于继续模拟工作流。

也可以从仓库根目录运行静态服务：

```sh
python3 -m http.server 8000
```

然后访问 <http://localhost:8000/docs/prototypes/curtain-airbag-workflow/>。

查看从新建工作流开始的完整交互，请打开 [interactive.html](interactive.html)。这些页面不需要安装依赖或构建。

## 缺少软件配置时的交互

- 原型首次使用时 HyperMesh 和求解器均未配置。上传 IGS 或点击开始导入时，自动打开“设置 → 仿真软件”，提示配置并聚焦 HyperMesh 批处理程序路径；导入、分区和网格任务在配置完成前不会启动。
- 点击“提交求解”时，按当前选择的本地软件、本地求解服务或服务端检查配置。缺少配置时自动打开同一设置弹窗，聚焦 LS-DYNA 路径或对应服务地址；不会显示已提交或开始求解。
- 关闭或取消设置会保留已选 IGS、车身 K 文件、模型及当前阶段。保存后返回当前步骤，由用户继续导入或提交求解。
- 可从左下角“设置”或右侧工作流标题栏的齿轮打开设置。原型配置仅保存在当前浏览器中；通过上方静态服务访问时，各阶段页面共用配置。可手动清空对应字段并保存，以复现未配置的情况。服务模式不要求填写本地 LS-DYNA 路径。

## 原型范围

- 文件列表、模型图、执行记录和求解结果均为模拟数据，用于评审界面和交互。
- 执行按钮通过本地模拟展示处理进度和阶段动画；页面不会调用 HyperMesh MCP、求解器或 HyperView。
- 文件选择只用于展示所选文件名，不读取文件内容，也不会上传文件。
- 分区、网格和后处理保留用户确认环节；组合求解需要先选择车身 K 文件。
- 提交求解前及求解运行中，在对话和操作区提示“求解通常需要数小时”，并说明耗时取决于模型规模、网格密度和计算资源；原型中的求解进度为模拟演示。
- “导出模拟摘要 / 导出报告摘要”下载文本摘要；列表中的 `.hm`、`.k`、`d3plot`、GIF 和 PPTX 是产物占位。
