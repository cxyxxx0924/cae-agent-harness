# 气帘仿真工作流界面原型

基于当前 CAE Agent 三栏布局的 HTML 交互原型，用于评审气帘仿真流程中的输入、工具执行、产物预览和用户确认。消息输入统一放在左侧对话区，右侧展示当前阶段、结果、文件列表和执行记录。

## 预览方式

直接用浏览器打开 [index.html](index.html)，通过缩略图进入各阶段页面。阶段页面顶部的“上一步 / 下一步”用于切换设计预览，页面内部的确认按钮用于继续模拟工作流。

也可以从仓库根目录运行静态服务：

```sh
python3 -m http.server 8000
```

然后访问 <http://localhost:8000/docs/prototypes/curtain-airbag-workflow/>。

查看从新建工作流开始的完整交互，请打开 [interactive.html](interactive.html)。这些页面不需要安装依赖或构建。

## 阶段页面

| 页面 | 展示内容 | 下一步 |
| --- | --- | --- |
| [01 · IGS 上传完成](01-igs-uploaded.html) | 气帘几何文件和轮廓预览 | 开始 AI 分区 |
| [02 · AI 分区完成](02-partition-completed.html) | HyperMesh 功能区、`.hm` 模型和分区截图 | 用户确认分区后生成网格 |
| [03 · 网格生成完成](03-mesh-completed.html) | 气帘 `.k` 文件和网格截图 | 用户确认网格后进入求解准备 |
| [04 · 车身 K 文件就绪](04-body-k-ready.html) | 已确认的气帘网格和上传的车身 `.k` 文件 | 提交组合求解 |
| [05 · 组合求解完成](05-solve-completed.html) | 组合主控文件和 `d3plot` 结果 | 进入 HyperView 后处理 |
| [06 · HyperView 后处理完成](06-postprocess-completed.html) | 部署动画、末态截图和关键视图 | 用户确认结果后生成报告 |
| [07 · 分析报告生成完成](07-report-completed.html) | 报告预览及完整产物列表 | 导出模拟摘要或新建一轮 |

`previews/` 保存总览页使用的 7 张原型缩略图，需要和 HTML 一起保留。各阶段页面包含自己的样式和脚本，可以独立打开。

## 原型范围

- 文件列表、模型图、执行记录和求解结果均为模拟数据，用于评审界面和交互。
- 执行按钮通过本地模拟展示处理进度和阶段动画；页面不会调用 HyperMesh MCP、求解器或 HyperView。
- 文件选择只用于展示所选文件名，不读取文件内容，也不会上传文件。
- 分区、网格和后处理保留用户确认环节；组合求解需要先选择车身 K 文件。
- “导出模拟摘要 / 导出报告摘要”下载文本摘要；列表中的 `.hm`、`.k`、`d3plot`、GIF 和 PPTX 是产物占位。
